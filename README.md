# 🎬 Catálogo de Filmes
Este é um projeto de catálogo de filmes que consome a API do TMDB (The Movie Database). Com essa aplicação, é possível visualizar os filmes populares, melhores avaliados, em cartaz, em estreia, além de pesquisar por qualquer filme.

## Tecnologias Utilizadas
- HTML
- CSS
- JavaScript (JS)
- Node.js
- EJS (Embedded JavaScript)
- API TMDB

## Funcionalidades
- Listagem dos filmes mais populares
- Exibição dos filmes melhores avaliados
- Filmes em cartaz nos cinemas
- Filmes que estrearão em breve
- Pesquisa por nome de filme

## Como Executar o Projeto
Clone o repositório:
```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

Instale as dependências:
```bash
npm install
```

Configure a chave da API:
Crie um arquivo .env na raiz do projeto com o seguinte conteúdo:
```bash
TMDB_API_KEY=sua_chave_api_aqui
```
Você pode obter sua chave em: https://www.themoviedb.org/settings/api

Execute o projeto:
```bash
npm run dev
```

Acesse no navegador:
```bash
http://localhost:3000
```
